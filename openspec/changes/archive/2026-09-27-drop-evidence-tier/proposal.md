# Proposal

## Why

The evidence tier (1 peer-reviewed … 4 commentary) worked against the forward-looking watch: the candidate-trend rule rewarded finished facts while the Vision wants early signals (tier 3–4 by definition). It duplicated what significance, source class, independence, reach and persistence already say, and a per-source tier ceiling added catalog upkeep nobody read.

## Changes

- Tier is removed from the catalog, the verdict, findings and cluster entries; files still carrying it keep reading.
- Rankings (strongest entry, theme sections, lead, source cap, duplicate folding) use significance, then recency.
- A candidate trend needs a primary source — a class other than aggregators or community — instead of a tier-1/2 finding; "strengthening" no longer needs a tier-1 entry.
- Catalog classes keep only an independence default.
